# Task 4: CI Permissions

The policy permits the deployment sequence and nothing else:

```text
authenticate to ECR
  -> push to one repository
  -> register an ECS task-definition revision
  -> pass two approved task roles
  -> update one ECS service
  -> read artifacts from one S3 bucket
```

`ecr:GetAuthorizationToken` and `ecs:RegisterTaskDefinition` use `Resource = "*"` because those AWS actions do not support the narrower resource scope needed here. ECR uploads, ECS service updates, `iam:PassRole`, and S3 access are restricted to configured ARNs. Role passing is also conditioned on `ecs-tasks.amazonaws.com`.

The policy does not allow IAM administration, S3 writes, ECR deletion, ECS service deletion or unrestricted role passing.

```bash
terraform init -backend=false
terraform validate
terraform test
```

`generated-policy-example.json` is a readable example rendered with the placeholder values. Before deployment I would inspect the policy generated by the plan for the target account.
